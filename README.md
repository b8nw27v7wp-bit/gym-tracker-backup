# 铁馆日志 Gym Tracker

微信小程序：专业健身训练记录工具。记录每次训练的动作、组数、重量、次数，自动计算训练容量（Volume）与个人纪录（PR），生成周容量趋势、训练热力图与部位训练分布统计。内置 278 个动作的专业动作库、43 篇健身知识文章与 5 套训练计划模板，支持自建计划。

纯前端 + 本地存储，无后端、无域名、零成本，个人主体可上线。

## 功能

### 训练记录
- 选部位 → 选动作 → 记组（重量 × 次数），一次训练可多动作、追加组、删除组
- 上次记录一键带入：动作卡显示"上次 8月11日 · 60kg × 8"标签（取最近正式组，跳过热身），添加时自动预填，组编辑器内可一键清空预填
- 组间休息计时器：30s/60s/90s/120s 快捷 + 自定义秒数，到点震动提醒；休息期间自动暂停训练计时、结束自动恢复（休息不计入训练时长）
- 训练计时可暂停/继续（暂停不计时长，显示累计暂停分钟）
- 已添加动作支持上移/下移排序（保存顺序与显示一致）
- 组级 RPE 记录（选填 1-10）+ 热身组标记（不计入统计）
- 本次训练计时（自动记录时长）+ 训练备注
- 训练页内动作搜索（跨部位）+ 常用动作按使用频率置顶
- 动作详情页一键"去记录"，直接跳转训练页并预选该动作
- 训练页"在动作库查看当前部位"入口：携带部位跳转动作库自动筛选，动作库顶部返回条一键回训练
- 历史记录：按时间倒序，展开查看明细（时长/备注/RPE/热身组），支持删除

### 训练体验（v2.24 对标 Strong/Hevy）
- **组间休息自动开始**：完成动作保存后自动按推荐秒数（热身 60s / 正式 90s）启动休息倒计时，可点停止跳过；可在设置关闭
- **历史训练编辑**：历史记录可修改——加载旧训练进草稿，保存覆盖原记录（保留原时间），支持放弃编辑
- **复制上次训练**：一键重复最近一次训练到草稿（对标 Hevy Repeat），动作/组数/上次重量次数预填
- **重量单位切换**：设置 kg/lb 全局切换，训练输入/上次记录/建议/历史/统计 PR 与容量/体重联动换算（存储统一 kg）

### 追踪与激励（v2.24 对标 Keep/Hevy/Fitbod）
- **连续打卡与成就**：当前/最长连续训练天数 + 9 枚成就徽章（首训/累计次数/连续天数/容量里程碑）
- **训练目标**：体重目标（起始→目标进度条）+ 最多 3 个力量目标（招牌动作最大重量 vs 目标）
- **肌肉恢复建议**：本周每肌群正式组数 vs 建议范围（胸/背/肩 8-16 组等），超练/欠练提示
- **身体围度追踪**：胸/腰/臀/臂/腿围记录 + 逐部位趋势 + 历史管理

### 训练计划与目标（v2.26）
- **训练日提醒**：本周计划待练训练日应用内提醒条（训练页/统计页，一键填充）；可申请微信订阅消息授权（真正推送需后端）
- **每周容量目标**：设定每周目标容量，统计页进度环实时显示本周进度，达标变绿
- **动作重量趋势图**：动作详情页展示每次训练最大重量曲线（训记式），kg/lb 自动换算

### 训练智能（v2.23.3）
- **渐进超负荷建议**：选动作时按最近 2 次训练自动建议本次重量/次数——进步 → 加重一档（<100kg +2.5 / <200kg +5 / 大重量 +10）；同重量加次也算进步；持平 → 保持重量目标 +1 次；回落 → 恢复优先
- **动作轮换提醒**：近 30 天同一动作使用 ≥8 次，自动推荐 1-2 个同部位替代动作
- **减量周检测**：近 3 周容量连续下降 ≥20% → 统计页提示"减量 40-60% 或休息 1-2 天"；连续上升 ≥30% → 提示冲击新 PR
- **1RM 趋势预测**：1RM 历史线性回归（≥3 点且上升），PR 卡展示"2 周后 1RM 预计 X kg"

### 训练功能扩展
- **超级组支持**：将两个动作标记为超级组，组间不休息连续完成
- **递减组支持**：组编辑器一键添加递减组，自动减重 25%
- **训练模板**：保存当前训练为模板，下次直接加载；支持删除模板
- **Tabata 计时器**：可自定义运动/休息时间、轮数、组数；自动循环计时，到点震动提醒

### 训练计划模式
- 5 套内置计划（新手全身 A/B/C、PPL 推拉腿、上下肢 A/B、减脂 4 日、居家无器械 3 日）共 17 个训练日
- 自建计划：新建/编辑/删除自己的计划模板（多训练日、按部位/搜索选动作、组数次数可调），与内置计划统一展示、一键填充
- 计划完成度：当日计划动作完成率进度条 + "今日已完成"徽标
- 本周计划打卡：设为本周计划后，训练页顶部显示今日训练日提醒条（点击一键填充），计划库页显示周进度卡
- 计划库一键填充训练草稿：组数/次数预填，力竭动作留空自填

### 专业动作库（278 个动作 × 9 部位）
- 部位：胸/背/腿（含小腿）/臀/肩/手臂/核心/有氧/游泳（前臂模块已移除，小腿并入腿，游泳为独立板块）
- 每个动作含：目标肌群、辅助肌群、器械、难度（入门/进阶/高级）、组间休息建议、分步动作要领、常见错误警示、训练要点
- 发力肌群：每个动作标注主要发力肌群 + 辅助发力肌群（文字标签），部位指南页同步展示
- 按部位/类型（复合/孤立）/难度筛选 + 关键字搜索
- 动作详情关联训练知识：部位训练要点（频率/常识/3 条技巧）、同部位推荐动作、关联知识库文章（关联阅读）
- 部位训练指南：按肌肉发力分区查看每个部位的训练动作（如胸部 → 上胸/中胸/下胸/夹胸），每区含训练处方（每周频率 × 组数 × 次数）、训练要点与动作列表（类型/器械标注）

### 游泳板块（7 个动作）
- 独立部位：综合游泳/自由泳/蛙泳/仰泳/蝶泳/浮板打腿/水中慢跑
- 按发力分区：拉主导（自由泳/仰泳练背阔肌）、推主导（蛙泳/蝶泳练胸肩）、腿部与基本功
- 每个泳姿含：目标肌群、分步要领、常见错误、休息建议与训练要点

### 健身知识库（43 篇文章，6 大分类）
- 训练原理：渐进超负荷、容量与强度、RM/RIR/RPE、组间休息、容量追踪法、念动一致、热身指南、伤病预防、肌肉收缩（向心/离心/等长）、神经适应与新手效应、NSCA 训练参数表、核心稳定、ACE IFT 模型
- 分化计划：全身/上下肢/推拉腿选型指南 + 计划模板、居家训练指南
- 营养饮食：蛋白质与增肌、减脂热量缺口、碳水化合物、脂肪与激素、运动补剂、营养误区
- 恢复睡眠：恢复三要素、频率指南、减量周、拉伸柔韧性、训练前健康筛查（PAR-Q）、行为改变与坚持
- 运动表现（对标 NSCA/ACE）：三大能量系统、周期化训练、增强式训练、速度与敏捷、体能测试、心率区间
- 术语表：从 1RM 到 Deload 的健身黑话速查

### 统计与数据分析
- 本周容量 + 上周环比、近 8 周容量 canvas 柱状图（本周高亮 + 数值标签）
- 训练热力图：近 12 周日历视图，颜色深浅 = 当日容量，一目了然训练节奏
- 训练频率：本周/累计/周均次数、本周部位覆盖
- 部位训练分布、招牌动作 PR（最大重量 / 最佳单组 / 最新估算 1RM）+ 1RM 迷你趋势柱 + 点击展开 1RM 大图曲线（canvas 折线图）
- **月度总结**：本月训练次数/总容量/新PR数/平均密度
- **肌群平衡分析**：推/拉/腿比例可视化 + 训练建议
- **训练密度趋势**：容量/时长比，衡量训练效率
- **周训练频率趋势**：最近 8 周每周训练次数
- **身体部位训练热力图**：GitHub 贡献图风格肌群矩阵——行 = 14 个肌群分组（肩/胸/背/腿…），列 = 近 12 周，格子色深 = 当周该部位训练组数（灰=未练，蓝系 4 档），点击部位行查看近 12 周组数/次数/全身占比（再点取消选中）

### 营养与热量管理
- 每日热量：基础代谢（BMR）/ 每日消耗（TDEE）/ 本周运动消耗（MET 估算）/ 增肌减脂建议区间 + 今日摄入与热量缺口
- 营养计算器：BMR/TDEE/蛋白质区间/增肌减脂热量（Mifflin-St Jeor）+ **BMI 体质指数** + **体脂率估算** + **宏量营养素分配** + **每日水分需求**
- 食物热量查询：**205 种**常见食物（8 大分类含调味酱料），按克数/份量快速计算热量，可记录到今日摄入
- **自定义食物**：用户可添加自己的食物到数据库
- **水摄入记录**：每日饮水量追踪，可自定义目标

### 个人中心与用户管理
- 微信登录：使用 open-type="chooseAvatar" + type="nickname" 获取头像和昵称
- 用户信息本地存储：登录后用户信息保存在本地，无需后端
- 个人中心页：展示用户头像、昵称、身体资料，提供数据管理和隐私说明入口
- 统计页顶部个人中心入口：显示用户信息预览 + 训练统计

### 数据与分享
- 数据管理：备份导出（剪贴板 JSON）/ 导入恢复（**先预览确认后覆盖** + 结构校验 + 1MB 上限，畸形数据自动过滤）/ 清空数据（二次确认）/ 容量监控
- **数据导出**：CSV 训练明细（UTF-8 BOM，Excel 打开中文不乱码）+ JSON 全量备份（训练/体重/计划/自定义动作等），写入文件可分享/复制剪贴板——数据属于用户，随时可带走
- 训练总结分享卡片（canvas 2d 生成图片保存相册）
- 隐私说明页 + 全 tab 页微信分享

### 自定义动作
- 自建动作进动作库，与内置 278 动作统一使用（搜索/详情/训练/统计全链路打通）
- 目标肌群 picker 限定已知肌群词（防污染热力图/肌群分析），器械/难度/要领/要点/休息秒数自定义
- 自建动作带"自建"角标，可编辑/删除（确认弹窗）；内置动作无编辑入口
- schema 迁移 v5：老用户升级自动补自定义动作/设置/围度/目标存储，不覆盖现有数据

## 技术要点

- 微信原生小程序（JS），无构建依赖，微信开发者工具直接导入运行
- 数据全部存于 wx.setStorageSync，单用户本地数据模型，带 schema 版本迁移机制（v1→v2→v3→v4→v5，v5 新增设置/围度/目标）
- `utils/util.js` 纯函数计算容量/统计，node 可单测（`node test.js`，687 项断言）
- 页面交互用不可变更新约定（深拷贝/路径 setData），避免同引用 diff 失效（BUG-003 教训）
- 组件化：set-editor（组编辑器）/ ex-card（动作卡片）/ empty-state（空态）自定义组件，样式隔离组件内自带全局类副本
- 内容数据模块化：动作库按 9 个部位拆文件，知识库按 3+1 主题拆文件，便于维护扩展
- UI 浅色极简风：白底、无边框卡片、大留白、Apple 系统字体、无装饰 emoji

注册（mp.weixin.qq.com，免费）→ 开发者工具上传代码 → 小程序备案（2023 年起强制，免费，约 1-2 周）→ 提交审核（工具-效率类目）→ 发布上线
