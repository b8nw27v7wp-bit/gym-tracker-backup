# 需求文档（Requirements）

版本：v2.26.0 | 更新：2026-08-15

## 1. 项目背景与目标

**项目名称**：铁馆日志（Gym Tracker）

**目标**：一款面向大众健身人群的微信小程序训练记录工具。核心价值：

1. 用"训练容量（Volume）"量化每次训练，让进步可测量
2. 内置专业动作库与健身知识库，降低新手学习门槛
3. 纯本地存储，数据隐私安全，零服务器成本，个人主体可上线

**成功标准**：完成从注册 → 开发 → 备案 → 提审 → 上线的完整微信小程序发布流程。

## 2. 用户画像

| 用户类型 | 特征 | 核心诉求 |
|---------|------|---------|
| 健身新手 | 刚入门，动作不熟 | 动作怎么做、怎么安排计划 |
| 业余训练者 | 规律训练 1-2 年 | 记录容量、追踪进步、看统计 |
| 纯力量爱好者 | 关注卧推/深蹲/硬拉成绩 | PR 记录、容量曲线 |

## 3. 功能需求

### 3.1 训练记录（P0 核心）

| 编号 | 需求 | 说明 |
|-----|------|------|
| F1 | 选部位选动作记组 | 部位 chips → 动作网格 → 组编辑（重量×次数） |
| F2 | 一次训练多动作 | 可连续添加多个动作，随时返回编辑 |
| F3 | 训练计时 | 进入页面自动计时，保存时记录时长 |
| F4 | 训练备注 | 可选文本备注（状态/感受） |
| F5 | 容量实时汇总 | 底部栏显示当前总容量/组数/分钟数 |

## 4. 非功能需求

| 类型 | 要求 |
|-----|------|
| 性能 | 无网络请求，页面切换无等待；278 动作数据 < 100KB |
| 存储 | 单用户本地 storage，容量上限 10MB，单 key 1MB，当前数据规模远低于上限 |
| 隐私 | 所有数据本地存储，不收集任何用户信息，无需用户协议弹窗 |
| 合规 | 类目"工具-效率"，个人主体可上线；无支付/社交/新闻等受限能力 |
| 兼容 | 基础库 3.4.0+，覆盖 iOS/Android 主流微信版本 |

## 5. 范围边界（v2 不做）

- 不做账号体系/云同步（v3 可考虑，需服务器与域名备案）
- 不做社交/排行榜（类目与审核风险）
- 不做支付/会员（个人主体限制）
- 不做视频教程（内容成本高，动作库以图文为主）
