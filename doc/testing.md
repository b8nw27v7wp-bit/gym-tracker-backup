# 测试文档（Testing）

版本：v2.3 | 更新：2026-08-12

## 1. 测试策略

- **数据层自动化**：计算/存储/内容完整性用 node 单测，`node test.js` 一键运行，数据层断言 + 页面冒烟（共 348 项，v2.9.0）
- **页面层冒烟**：mock `Page`/`wx` 实跑页面交互逻辑（编辑/保存流程），见第 4 章
- **手工**：页面渲染与视觉在微信开发者工具中验证（见第 5 章）
- **回归**：任何数据层改动后必须 `node test.js` 全绿；页面逻辑改动后跑冒烟测试再提交

## 2. 自动化测试环境

test.js 通过 mock 全局 `wx` 对象（内存 Map 实现 get/setStorageSync），使 utils 层脱离小程序运行：

```js
global.wx = {
  _store: {},
  getStorageSync(key) { return this._store[key]; },
  setStorageSync(key, val) { this._store[key] = val; }
};
```
