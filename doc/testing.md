# 测试文档（Testing）

版本：v2.0 | 更新：2026-08-11

## 1. 测试策略

- **自动化**：数据层（计算/存储/内容完整性）用 node 单测，`node test.js` 一键运行，32 项断言
- **手工**：页面交互与渲染在微信开发者工具中验证
- **回归**：任何数据层改动后必须 `node test.js` 全绿再提交

## 2. 自动化测试环境

test.js 通过 mock 全局 `wx` 对象（内存 Map 实现 get/setStorageSync），使 utils 层脱离小程序运行：

```js
global.wx = {
  _store: {},
  getStorageSync(key) { return this._store[key]; },
  setStorageSync(key, val) { this._store[key] = val; }
};
```

## 4. 手工测试清单（开发者工具）

| 模块 | 用例 |
|-----|------|
| 训练页 | 选部位→选动作→填组→完成动作→继续添加→保存；空组过滤；至少保留一组；计时递增；备注保存；计划填充（计划库→开始训练→草稿预填） |
| 计划库 | 计划切换；日清单动作/组次展示；力竭动作"自填"标记；开始训练跳转填充 |
| 动作库 | 部位切换；类型/难度筛选；搜索"深蹲"；点击进详情 |
| 动作详情 | 信息条/步骤/错误/贴士渲染；"去记录"跳回训练页且预选动作 |
| 知识库 | 分类切换；文章列表；详情渲染段落与列表 |
| 历史页 | 展开/收起；时长与备注显示；删除二次确认 |
| 统计页 | 无数据显示空态；有数据后频率/容量/柱状图/分布/PR 渲染；新保存训练后数据刷新；本周简报数字正确；体重记录（非法输入拦截/趋势图渲染） |
| 边界 | 全部输入为空时保存提示；重量/次数输字母（type=digit/number 限制）；切后台再回前台计时续走 |

## 5. 回归流程

1. `node test.js` 全绿
2. 开发者工具编译无报错
3. 手工清单按改动模块抽查
4. 提审前完整跑一遍手工清单 + 手机真机预览
