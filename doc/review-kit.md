## 2. 服务内容描述（提审时粘贴）

```
铁馆日志是一款健身训练记录工具。功能包括：
1. 训练记录：选择动作并记录每组重量、次数，自动计算训练容量，支持训练计时、备注、RPE 自感强度与热身组标记；
2. 训练计划：内置新手全身、推拉腿、上下肢、减脂、居家无器械 5 套计划，支持自建计划模板，可一键填充到训练记录并显示当日完成进度；
3. 动作库：内置 173 个健身动作，含动作要领、常见错误、目标肌群、组间休息建议，支持按部位/类型/难度筛选与搜索，动作详情关联训练知识与相关文章；
4. 知识库：内置 30 篇健身知识文章（训练原理、分化计划、营养饮食、恢复睡眠、术语表）与营养计算器；
5. 数据统计：训练容量趋势、训练热力图（近 12 周日历）、个人纪录（PR）与 1RM 趋势、体重记录、训练频率等，全部基于用户本地数据生成。

数据说明：所有数据（训练记录、体重记录、自建计划）仅保存在用户手机本机微信缓存中，本应用不搭建服务器、不发起点任何网络请求、不采集任何用户信息，无需登录即可使用全部功能。
```

## 3. 类目选择依据

- 主类目：**工具 → 效率**（个人主体可选类目）
- 不涉及：医疗健康指导（知识库内容全部表述为"建议/参考"，无治疗康复用语）、社交、支付、资讯新闻
- 若审核要求补充类目：可尝试"生活服务 → 生活记录"（备用）

## 5. 审核信息填写模板

- **功能页面**：勾选全部 15 个页面
- **测试账号**：本应用无需登录，无需账号（选填说明"无需账号，所有功能直接可用"）
- **隐私保护指引**（后台必填）：逐条填写——
  - 用户信息类型：不收集任何用户信息
  - 存储权限：仅在用户主动"保存分享图片到相册"时使用，可关闭
  - 说明：所有数据本地存储，见隐私说明页

## 6. 常见拒审原因与对策

| 拒审原因 | 对策 |
|---------|------|
| 类目与功能不符 | 保持"工具-效率"，描述突出"本地记录工具" |
| 涉及健康/医疗类目 | 知识库避免"治疗/康复/诊断"表述，统一用"建议/参考"；已过审内容自检 |
| 隐私协议缺失 | 后台填写隐私保护指引（见第 5 节），页面内有隐私说明页 |
| 截图与描述不符 | 按第 4 节清单重截真机图 |
| 功能页面未全部勾选 | 提审时勾选全部 13 个页面 |
