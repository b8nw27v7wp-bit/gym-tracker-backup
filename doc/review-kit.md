## 2. 服务内容描述（提审时粘贴）

```
铁馆日志是一款健身训练记录工具。功能包括：
1. 训练记录：选择动作并记录每组重量、次数，自动计算训练容量，支持训练计时、组间休息、RPE 自感强度与热身组标记，保存后可编辑/复制上次训练；
2. 训练计划：内置新手全身、推拉腿、上下肢、减脂、居家无器械 5 套计划，支持自建计划模板，一键填充训练记录，显示当日完成进度与待练提醒；
3. 动作库：内置 189 个健身动作，含动作要领、常见错误、目标肌群、组间休息建议，支持筛选搜索与自定义动作，动作详情含重量趋势图；
4. 知识库：内置 30 篇健身知识文章（训练原理、分化计划、营养饮食、恢复睡眠、术语表）与营养计算器、食物热量查询；
5. 数据统计：训练容量趋势、训练热力图与肌群热力图、个人纪录（PR）与 1RM 趋势、每周容量目标进度环、训练周报、连续打卡与成就、肌肉恢复建议、体重与身体围度记录，全部基于用户本地数据生成。

数据说明：所有数据（训练记录、体重、围度、目标等）仅保存在用户手机本机微信缓存中，本应用不搭建服务器、不发起点任何网络请求、不采集任何用户信息，无需登录即可使用全部功能。
```

## 5. 审核信息填写模板

### 5.1 隐私接口声明清单（重要）

> 2023 年起微信对隐私接口强制声明，**未声明的接口在真机会被拦截、审核可能拒绝**。在后台「设置 → 服务内容声明 → 用户隐私保护指引」逐条填写：

| 隐私接口 | 触发场景 | 用途说明 |
|---------|---------|---------|
| `wx.getClipboardData` / `wx.setClipboardData` | 数据管理页导出备份 / 导入恢复 | 用户主动备份与恢复本地数据 |
| `wx.saveImageToPhotosAlbum` | 历史页/统计页分享卡片保存 | 保存用户主动生成的分享图片 |
| `wx.requestSubscribeMessage` | 个人中心开启"训练日提醒"（可选） | 申请订阅消息授权，用于训练日提醒推送 |
| `wx.getSystemInfoSync` | 各页 canvas 绘制 | 获取屏幕像素比用于高清绘图（可勾选"设备信息"） |
| 头像/昵称（`chooseAvatar` / `nickname`） | 个人中心设置头像昵称（可选） | 本机展示，不上传 |

> 若后台隐私指引只允许勾选已有预设类型，可按微信提示如实选择对应项；**全部数据本地存储、无网络上传**，在"收集信息说明"中明确写出这一点。

## 6. 常见拒审原因与对策

| 拒审原因 | 对策 |
|---------|------|
| 类目与功能不符 | 保持"工具-效率"，描述突出"本地记录工具" |
| 涉及健康/医疗类目 | 知识库避免"治疗/康复/诊断"表述，统一用"建议/参考"；已过审内容自检 |
| 隐私协议缺失/不完整 | 后台隐私保护指引逐条声明（见 §5.1）；页面隐私说明页已更新对齐 |
| 隐私接口未声明 | `wx.requestSubscribeMessage`（订阅消息）、`wx.getSystemInfoSync`（设备信息）等全部声明 |
| 截图与描述不符 | 按第 4 节清单重截真机图（含新增的围度/目标页） |
| 功能页面未全部勾选 | 提审时勾选全部 19 个页面 |
