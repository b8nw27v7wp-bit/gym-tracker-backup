# 项目路线图（Roadmap）

版本：v2.1 | 更新：2026-08-11

> 本文档定义项目发展方向与优先级。每个方向完成时更新状态并记录到 changelog.md。
> 优先级定义：P0 核心可用 / P1 重要增强 / P2 锦上添花

## 方向一：训练计划模式（P0 · 进行中）

**目标**：把知识库中的计划模板变成可执行的结构化计划库，一键填充到训练记录。

| 任务 | 状态 |
|-----|------|
| data/plans.js：结构化计划库（新手全身 A/B/C、PPL 推拉腿、上下肢 A/B） | ✅ 完成 |
| pages/plans：计划库页面（计划列表 → 日清单 → 动作详情） | ✅ 完成 |
| 训练页"一键填充"：计划日 → 训练草稿（组数/次数预填，重量留空） | ✅ 完成 |
| 计划完成度：当日计划动作完成率显示 | 待办 |
