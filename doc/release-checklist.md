# 上线流程清单（Release Checklist）

版本：v2.26.0 | 更新：2026-08-15

> 个人主体、零成本路线。从注册到上线预计 2-4 周（主要时间在备案与审核等待）。

## 阶段 1：注册小程序账号（约 30 分钟）

1. 打开 mp.weixin.qq.com → 右上角"立即注册" → 选「小程序」
2. 邮箱注册（需未注册过公众号/小程序的有效邮箱）→ 激活邮件
3. 主体类型选「个人」→ 填写身份证实名信息 → 微信扫码绑定管理员
4. 完成后登录后台，记下 **AppID**（开发管理 → 开发设置）

> 个人主体免费，无需营业执照。一个身份证只能注册 1 个个人小程序（可随时注销重新注册）。

## 阶段 2：导入项目开发（可与备案并行）

1. 下载微信开发者工具稳定版：developers.weixin.qq.com/miniprogram/dev/devtools/download.html
2. 「导入项目」→ 目录 `E:\ts\gym-tracker` → 填入 AppID
   - 若 project.config.json 中 appid 仍是 `touristappid`，导入时直接填自己的 AppID 会提示确认，或在工具中修改
3. 「编译」检查无报错 → 「预览」生成二维码，手机扫码真机体验
4. 按 doc/testing.md 手工清单跑一遍

## 阶段 3：小程序备案（强制，免费，约 1-2 周）

> 2023 年 9 月起，小程序必须完成备案后才能发布上线。个人主体备案免费。

1. 后台「设置 → 基本设置 → 小程序备案」进入备案流程
2. 准备材料：
   - 身份证正反面照片
   - 管理员本人人脸核验（微信扫码完成）
   - 居住地/通讯地址信息
3. 填写备案信息（主体性质选"个人"，服务内容如实填写"健身记录工具"）
4. 提交后约 1-2 周通过（短信/邮件通知）。审核期间可继续开发

> 备案与代码审核相互独立：备案期间可以上传代码、开发调试，但**发布按钮需备案通过后才有**。

## 阶段 4：上传代码 + 提审（约 1-7 天）

1. 开发者工具右上角「上传」→ 填版本号（如 1.0.0）+ 项目备注
2. 后台「版本管理 → 开发版本」→ 找到刚上传的版本 →「提交审核」
3. 填写审核信息：
   - 功能页面：勾选全部 **19 个页面**
   - 类目：**工具 → 效率**（个人主体可选类目之一）
   - 服务内容：`健身训练记录工具：记录训练动作/组数/重量/次数，计算训练容量与个人纪录，内置动作库与健身知识，所有数据本地存储，不涉及用户信息收集`
4. **隐私协议**（重要，2023 年起隐私接口强制声明，未声明真机拦截 + 可能拒审）：
   后台「设置 → 服务内容声明 → 用户隐私保护指引」逐条声明以下接口——
   - `wx.getClipboardData` / `wx.setClipboardData`（数据导出/导入备份）
   - `wx.saveImageToPhotosAlbum`（分享卡片保存相册）
   - `wx.requestSubscribeMessage`（训练日提醒订阅，可选）
   - `wx.getSystemInfoSync`（设备信息，canvas 高清绘图）
   - 头像/昵称（`chooseAvatar`/`nickname`，可选，本机展示）
5. 提交等待审核（通常 1-3 天，最长 7 天）

### 常见拒审原因与对策

| 拒审原因 | 对策 |
|---------|------|
| 类目与功能不符 | 保持"工具-效率"，描述中强调是"本地记录工具" |
| 服务内容描述不清 | 按上面模板写，突出"本地存储、无网络请求" |
| 功能页面截图缺失 | 手机真机截图每个页面各一张（19 页） |
| 隐私接口未声明 | 见阶段 4 第 4 步清单，订阅消息/设备信息/头像昵称都需声明 |
| 涉及医疗/健康指导 | 知识库内容用词注意：表述为"训练建议/参考"，避免"治疗/康复/诊断"类医疗用语 |

## 阶段 5：发布上线

1. 审核通过后（后台状态"审核通过"）→ 点「发布」
2. 发布后约 1-3 小时生效，微信搜索小程序名称即可找到

## 阶段 6：上线后维护

| 事项 | 说明 |
|-----|------|
| 版本更新 | 开发 → 上传 → 提交审核 → 发布，迭代流程相同 |
| 用户反馈 | 后台「管理 → 用户反馈」查看 |
| 数据 | 本地存储数据跟随用户设备，卸载小程序即清空（需在简介中说明"数据存于本机"） |
| 性能 | 278 动作 + 43 篇文章打包体积小，无包体超限风险（主包 < 2MB 要求） |

## 时间线总览

```
Day 1    注册账号 + 安装工具 + 导入项目编译通过
Day 1-3  真机测试 + 提交备案
Day 1-14 备案审核（并行：继续打磨功能/补测试）
Day 14+  备案通过 → 上传代码 → 提交审核
Day 15-21 审核通过 → 发布上线 ✅
```
